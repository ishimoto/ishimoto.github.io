TreasureBoat — Support

Help for the TreasureBoat framework, the TreasureBoat IntelliJ plugin, and the TBConnect app.

Need a person? Write to office@treasureboat.org. Tell us which tool, what you expected, and what happened instead — that is usually enough to work it out.

TBConnect

TBConnect is a menubar app for macOS. It asks your TreasureBoat server which project URLs are shared with you, lists them in the menubar, and opens the one you click in your browser. It needs macOS 26 or newer.

It lives in the menubar, not the Dock

There is no Dock icon and no window until you open one, which is deliberate for something you use a dozen times a day. That also means ⌘Q from another app will not quit it — click the menubar icon and choose Quit TBConnect.

The menu says “No shared projects”

The call worked; there is simply nothing shared with you yet. Project links are shared by whoever administers your TreasureBoat server, either with everyone or with you individually. Ask them to add you.

It says no TreasureBoat ID is set

Open Settings… from the menu and either enter your TreasureBoat ID, or pair this Mac (below). If you do not have an ID yet, request one at treasureboat.org.

Pairing this Mac

Pairing is the better way to identify a Mac, because the credential lives in the Keychain instead of being typed. In Settings… choose Pair this Mac. A QR code appears; scan it with the Approve App screen in the TreasureBoat app on your phone. Once approved, the Mac identifies itself with that pairing and the typed ID is no longer used.

Unpair removes the credential from this Mac and forgets the cached list. You can also remove the device from your phone, which revokes it everywhere.

The list is there but marked as cached

TBConnect keeps the last list it received so the links are available when you are offline. If a refresh fails, the previous list stays on screen and is marked as cached rather than being emptied — a list from an hour ago is more useful than none. It refreshes when you open the menu, and hourly on its own.

The IntelliJ plugin

TreasureBoat Coding Tools is free on the JetBrains Marketplace. Install it from Settings → Plugins → Marketplace and restart the IDE.

To activate it, put your TreasureBoat ID into Settings → Tools → TreasureBoat → License and click Receive License. The licence is fetched and installed for you. If retrieval fails, check that the ID is correct and that the machine can reach treasureboat.org; the server and shared-secret fields can be left empty, and default to production.

Licences and TreasureBoat IDs

A free TreasureBoat ID starts a 90-day trial of the full environment. After that you continue with a Basic, Pro or Ultra licence. Questions about editions, renewals or invoices go to office@treasureboat.org.

Reporting a problem

What helps most:

  • Which tool and which version — TBConnect shows its version at the top of Settings…, and the plugin shows its own under About.
  • What you did, what you expected, and what happened.
  • The exact wording of any message, including anything after a code number.
  • Your macOS or IDE version, if it seems relevant.
