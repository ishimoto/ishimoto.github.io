TreasureBoat Mobile

Your TreasureBoat servers, on iPhone and iPad.

This covers what the app does today. It will grow as features land — if something here is missing or wrong, write to office@treasureboat.org.

What it is

TreasureBoat Mobile reaches the TreasureBoat servers you work with: it browses their data, plays their video channels, holds your two-factor codes, and approves the other devices you sign in from. It needs iOS 26.5 or newer.

It is also the app the other TreasureBoat apps ask for. When TreasureBoat Desktop, TreasureBoat Vision or TreasureBoat TV show a pairing code, this is where you approve it.

Connections

A connection is one TreasureBoat server. Add as many as you work with; each keeps its own identity, and switching between them does not sign you out of the others.

If a connection stops working after a server has been moved or rebuilt, Repair re-establishes it without losing anything else you have configured.

Approving another device

When you sign in on a Mac, an Apple Vision Pro or an Apple TV, that device shows a code and waits.

  • Approve App — scan the QR the other device is showing. This is how TreasureBoat Desktop and TreasureBoat TV are paired.
  • Type the code — used for Apple Vision Pro, where the code is displayed inside the headset and no camera can reach it.

Approving stores a credential on that device, in its Keychain. Nothing is typed there again, and you can revoke it later from the TreasureBoat app.

Two-factor codes

TreasureBoat Mobile holds TOTP codes for the services you use, the same as any authenticator app. Add one by scanning its QR.

These seeds travel with you. They are written to the iCloud Keychain, so a new iPhone has them without you enrolling everything again — which is the failure case that matters, since losing a seed can mean losing the account it protects.

Device pairings are the opposite: they stay on the device that was approved and never sync, because a pairing identifies that device and nothing else.

Watching and reading

The video channels your servers publish are here too, the same ones TreasureBoat Desktop and TreasureBoat TV show. The app also renders the documents a server sends: PDF, Markdown and web pages, without leaving the app.

Server data

Lists of records from a server can be browsed, filtered, opened and edited, as far as your account is allowed. What you can see and change is decided by the server, not by the app.

If something is not working

Nothing loads from a server

Check the connection. If a message mentions a method that does not exist, the app is talking to a server that has not been updated yet.

A pairing will not complete

The other device has to still be showing its code — codes expire. If approval succeeds but the other device says the credential could not be saved, the problem is on that device's Keychain, not here.

A two-factor code is rejected

TOTP depends on the clock. If the phone's time is set manually and has drifted, the codes will be wrong even though the seed is right.
