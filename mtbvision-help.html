MTBVision

TreasureBoat video channels on Apple Vision Pro.

This covers what the app does today. It will grow as features land — if something here is missing or wrong, write to office@treasureboat.org.

What it is

MTBVision shows the video channels on your TreasureBoat server: channels on the left, the videos of the selected channel on the right, and each video in a window you can place wherever you like. It needs visionOS 26 or newer.

Where the controls are

Below the window there is a small bar — an ornament — holding Refresh, Monitors, Help and Settings. That is where this app keeps everything a Mac would put in a menu bar, because visionOS has no menu bar.

Getting started

You can use it without setting anything up. With no identity configured the app shows the channels shared with everyone, so it is useful immediately.

Seeing the channels shared with you

Channels can be shared with everybody, or with particular people. To see the ones shared with you, the app has to know who you are — either by pairing, or by a TreasureBoat ID typed into Settings. Pairing is preferred, because the credential is stored rather than typed.

Pairing: type the code, do not try to scan it

This is the one thing that works differently here than on a Mac or a TV.

In Settings → Pair this device a QR code appears together with a short code such as 2YAK-V4C4. On any other device you would scan the QR with your phone. You cannot do that here — the QR is being displayed inside the headset you are wearing, where no phone camera can ever see it.

So read the code instead. Open the TreasureBoat app on your phone, go to Approve an App, and type the code into the field below the Scan button. The letters are chosen so they cannot be misread: there is no I, no O, no 0 and no 1 in a pairing code. Include the hyphen, or type it without — the field puts it back either way.

The code is good for a few minutes. If it expires, start a new pairing; nothing is lost by doing so.

Unpair this device removes the credential and returns to the shared view.

Watching

Select a channel, then look at a video and pinch. A window opens showing the poster, the description and a Play button. Nothing is downloaded until you press Play, so opening a video by mistake costs nothing.

Each video opens in its own window, so you can place one where you want it and carry on browsing the list — or leave one playing while you look at something else.

Likes

The heart beside a video shows how many people liked it, and is filled when you are one of them. A like cannot be taken back — the server refuses a second one, so the heart becomes an indicator once given.

Liking needs your own identity. While the app is showing the shared view the count is visible but there is nothing to press: everyone reading publicly resolves to the same identity, so one anonymous like would be everybody's.

Monitors

The Monitors button in the ornament lists the TreasureBoat Monitors you have configured and opens the chosen one in its own window. Add and remove them under Settings → Monitors.

Access ID

When this device is paired, Settings shows an Access ID with a Copy button beside it. It identifies you to a Monitor without revealing your TreasureBoat ID, and a server administrator can allow it so that this device is accepted wherever it is — rather than allowing an IP address that has to be edited when you travel.

Each Monitor has its own Send my access token to this server setting, ticked automatically for the port Monitors normally use. Anything else you add is not sent a token unless you say so.

If something is not working

The phone says no pairing request was found

Either the code has expired — they are short-lived — or a character was mistyped. Start a new pairing on the headset and read the new code carefully; remember that I, O, 0 and 1 never appear in one, so a character that looks like any of them is something else.

No channels appear

Check the server in Settings. If a message mentions a method that does not exist, the app is talking to a server that has not been updated yet.

A channel picture is missing

The picture is named by the server. If the name refers to something this app does not carry and is not a web address, a placeholder is shown rather than an error — the channel itself still works.
