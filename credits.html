Open-source components

What the TreasureBoat apps include, and the notices those licences ask for.

Listed per app, because they do not all include the same things. Where a licence requires its notice to be reproduced, it is reproduced here in full rather than linked.

Which apps include what

AppComponents
MTBMobile (iOS)swift-markdown, swift-cmark
MTBDesktop (macOS)none
MTBVision (visionOS)none
TBConnect (macOS)none

The two components below come with the Markdown renderer, which only MTBMobile currently ships. The other apps contain no third-party code.

swift-markdown

github.com/swiftlang/swift-markdown — a Swift package for parsing, building and rendering Markdown, from the Swift project. Used to render documentation inside the app.

Licensed under the Apache License, Version 2.0. The full text is available at apache.org/licenses/LICENSE-2.0.

swift-cmark

github.com/swiftlang/swift-cmark — the CommonMark parser underneath swift-markdown, derived from cmark and cmark-gfm.
