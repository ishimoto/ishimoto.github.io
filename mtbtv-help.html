TreasureBoat TV

TreasureBoat video channels on the television.

This covers what the app does today. It will grow as features land — if something here is missing or wrong, write to office@treasureboat.org.

What it is

TreasureBoat TV shows the video channels on your TreasureBoat server on Apple TV: a grid of channel artwork, the videos of the channel you choose, and playback full screen. It needs tvOS 26.5 or newer.

The channels carry education and user-support videos for the TreasureBoat frameworks, and grow as more are published.

Getting started

You can use it without setting anything up. With no identity configured the app shows the channels shared with everyone, so it is useful immediately and you can see what it does before deciding to configure it.

Seeing the channels shared with you

Channels can be shared with everybody, or with particular people. To see the ones shared with you, the app has to know who you are. There are two ways, and it prefers the first:

  • Pair this Apple TV — open Settings and choose to pair. A QR code appears on the television; scan it with the Approve App screen in TreasureBoat Mobile on your phone. The credential is then stored in the Keychain rather than typed — which matters here more than anywhere, because nobody wants to enter a code with a remote.
  • A TreasureBoat ID — entered in Settings. Used when the Apple TV is not paired.

Unpairing removes the credential and returns to the shared view.

Watching

Channels appear as a grid of artwork. Select one and its videos are listed with a still, a headline and a like count. Select a video to play it full screen.

Apple TV shows one screen at a time, so the player takes the whole display rather than opening a window — on the Mac and in Apple Vision Pro the same video opens in a window you can place.

Likes

The heart beside a video shows how many people liked it, and is filled when you are one of them. A like cannot be taken back — the server refuses a second one, so the heart becomes an indicator once given.

Liking needs your own identity. While the app is showing the shared view, the count is visible but there is nothing to press: everyone reading publicly resolves to the same identity, so one anonymous like would be everybody's and could never be undone.

About

The About screen carries the story of the Takarabune — the treasure ship of Japanese folklore that gives TreasureBoat its name — in both English and Japanese.

What is not here

There are no Monitor windows and no in-app documentation on Apple TV. Both are built on a web view, and the framework that provides it is not part of the tvOS SDK at all. Use TreasureBoat Desktop or TreasureBoat Vision for those.

If something is not working

No channels appear

Check the server in Settings. If a message mentions a method that does not exist, the app is talking to a server that has not been updated yet.

A channel picture is missing

The picture is named by the server. If the name refers to something the app does not carry and is not a web address, the app shows a placeholder rather than an error — the channel itself still works.

Pairing says the credential could not be saved

The server approved the Apple TV but the Keychain refused to store the result. The message names the reason. Until it is stored the pairing is not usable, so pair again once the cause is fixed.
