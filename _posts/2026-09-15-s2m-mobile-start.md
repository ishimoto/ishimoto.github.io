## Videos

This is a section for displaying Videos for Documentation or Development.
Some sample Videos (Shared Free Videos) are displayed.

## Authenticator

The Authenticator is a feature that allows users to generate one-time passwords (OTPs) for added security 
when logging into their accounts. It is commonly used in conjunction with two-factor authentication (2FA) 
to provide an extra layer of protection against unauthorized access.

The empty screen for Two-Factor Authentication. (2FA) here we are able to add accounts. 
More to that in a later 2FA post. 

## Technical Information

The Keys get saved in the Keychain and synced to all your devices.

![Authenticator](/assets/S2M/Mobile/NoConnection/Authenticator.jpeg)

## About

The about Screen shows information about the app version, and when available, the current connected
Server information like Server name, Signed-in userName, and current Domain.

Also, it provides Links to: 

* Credits
* License
* Privacy
