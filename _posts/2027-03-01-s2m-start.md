# Server Side Setup and Preparation for Authorization

Before we start, please make sure you have the latest version of the S2M app installed on your device.  
If the application is not released yet, you can download the latest version from Testflight. (Coming soon)

On the Web App, the entrance to all this features are in the **EditMyself** section.

![MySelf Button](/assets/S2M/MySelfButton.png)

Clicking on this Button will show the User Information Panel.

![MySelf Button](/assets/S2M/UserPanel.png)

Bellow the Accessibility Features, you will find the **My Account** section.

Clicking on the **My Account** button will show the Sangria Page: **EditMySelfTBPerson**.

There are two new kinds of rules inside the Frameworks:

### Two-Factor Authentication  

`945 : EN = 'TBPerson' => tabTwoFactor = ("[TwoFactor@property=org.treasureboat.twofactor.allowed]", "(TwoFactor)", "twoFactorUserID") [Assignment]`

![Overview](/assets/S2M/TwoFactor/Overview_2FA.png)

For using 2FA the property `org.treasureboat.twofactor.allowed=true` has to be set. 

Other Properties:

* `org.treasureboat.twofactor.secure` to secure and encrypt the data on disk
* `org.treasureboat.twofactor.id` The text that gets displayed on the device
* `org.treasureboat.twofactor.autoLogin` true - allow auto login, false – will not allow auto login and ask all info every time
* `org.treasureboat.twofactor.cookie.lifetime` The time of the two-factor cookie lifetime in hours

---

### Mobile Authentication

`945 : EN = 'TBPerson' => tabS2M = ("[Mobile@policy=Policy.Sangria.mobile.login]", "(Mobile)", "mobileLogin", "pairedDevices") [Assignment]`

---

![Overview](/assets/S2M/Mobile/Overview_Mobile.png)

### How to setup on your Server

Both are prebuilt and can be used with this new feature `tabInject` we can inject them into the **EditMySelfTBPerson** page.

`1000 : (EN = 'TBPerson' and PC = 'EditMySelfTBPerson') => tabInject = ("tabTwoFactor", "tabS2M") [Assignment]`
