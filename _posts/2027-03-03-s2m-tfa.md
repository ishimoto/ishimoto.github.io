# Two Factors Authentication

First Login into the application. After that we are authenticated and we know the user credentials and of  
course we know all the Server information.

This is the best timing for setting up the Two-Factor Authentication.

![Overview](/assets/S2M/TwoFactor/Overview_2FA.png)

## 1. Download

So on the Screen bellow, you have currently two options of Mobile Authenticater apps to download:

* iOS → Twilio Authy
* Google Play → Twilio Authy Authenticator

Because the link can be different for a country depending on the language.  
The current solution is it is backed into the Localization.

* TBWTwoFactor.Path.AppStore
* TBWTwoFactor.Path.GooglePlay

In the future we will be able to provide MTB Mobile for handling 2FA. 

## 2. Scan the QR Code

Click on the Authenticator Navigation to scan the QR Code.

![Authenticator Navigation](/assets/S2M/TwoFactor/Navigation.jpeg)

On the Authenticator Screen you will see a button to add a add account. Click on it.

![Add Button](/assets/S2M/TwoFactor/Authenticator.jpeg)

The **Add Account** Screen has a Scan 2FA QR Code. Click on it for scanning the QR Code.  
In some situations it is possible to add your account manually.

The data get saved into the Key Chain.

When you clicked on this Button the Camera will start scanning the QR Code.

![Add Accont](/assets/S2M/TwoFactor/AddAccount.jpeg)

After a successful scan you will see a list of accounts.

![List Accont](/assets/S2M/TwoFactor/ListAccount.jpeg)

## 3 Enter Code to verify correctness

Add the code into the field and click on the **Confirm your Code** Button.

![Verify](/assets/S2M/TwoFactor/ServerVerify.png)

If this is successful you will see **Two Factor Authentication is on** message.

![Success](/assets/S2M/TwoFactor/Success.png)

Also now you have this red button to disable 2FA.
